Récupération des nouveaux DPE : mode d'emploi pour 2026

Les changements liés au Diagnostic de Performance Énergétique (DPE) à partir du 1er janvier 2026 sont essentiels à connaître pour optimiser les fiches produits.

🧠 À retenir

  • Un nouveau mode de calcul du DPE pour les chauffages électriques entre en vigueur.
  • Possibilité d'amélioration de la note pour certains DPE calculés avant cette réforme.
  • Vérifiez votre DPE pour déterminer si une mise à jour est nécessaire.

⚡ Moments forts

Pour mettre à jour votre DPE, voici les étapes à suivre :

  • Recherchez une attestation sur le site de l'ADEME.
  • Accédez à votre fiche Eglantine pour consulter votre ancien DPE.
  • Si le numéro ADEME est cliquable, cliquez dessus pour obtenir l'attestation.
  • Si non cliquable, copiez le numéro et recherchez-le manuellement sur le site de l'ADEME.
  • Téléchargez l'attestation et envoyez-la à l'animation avec le numéro de mandat.
Vérifiez vos DPE dès maintenant pour afficher de meilleures notes pour les produits concernés !
